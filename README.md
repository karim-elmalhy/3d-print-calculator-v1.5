# 🏭 نظام إدارة ورشة ELMALHY.3D (Workshop Manager)

نظام إداري متكامل ومصمم خصيصاً لورش ومشاريع الطباعة ثلاثية الأبعاد (3D Printing Workshops) في السوق المصري، يغطي دورة العمل الشاملة من استلام الطلب والتسعير وحتى إدارة المخزون، خط الإنتاج والطباعة، وفحص الجودة، وحساب التكاليف والأرباح المحققة.

---

## 🚀 المميزات الرئيسية

### 1. 📊 لوحة التحكم الإدارية (Executive Dashboard)
- **مؤشرات مالية دقيقة**: إجمالي المبيعات المؤكدة، التكاليف المباشرة وغير المباشرة، وصافي الأرباح، ونسبة هامش الربح.
- **مؤشرات تشغيلية حيوية**:
  - **ربح كل ساعة تشغيل للطابعة (Profit per Print Hour)**.
  - **معدل فشل الطباعة (Failure Rate)** لمراقبة جودة الإنتاج وهدر الخامات.
  - **معدل استغلال الماكينة (Utilization Rate)** لمتابعة كفاءة التشغيل.
- **متابعة الطلبات**: مراقبة الطلبات قيد التصنيع وتنبيهات فورية للطلبات المتأخرة عن مواعيد التسليم.
- **الأكثر مبيعاً وربحية**: ترتيب المنتجات حسب عدد القطع المباعة والأعلى تحقيقاً للأرباح.
- **مركز تنبيهات المخزون**: إنذار تلقائي عند وصول أي صنف أو خامة لحد إعادة الطلب.

### 2. 🏷️ إدارة المنتجات والعملاء (Catalog & CRM)
- كتالوج منتجات متكامل لقطع الديكور والهدايا والقطع الهندسية.
- توليد تلقائي لأكواد **SKU** الموحدة لتتبع المنتجات.
- ربط المنتج بمستلزماته التجميعية (مثل مغناطيس النيوديميوم، المسامير، وحدات LED) ومواد التغليف المطلوبة.
- جدول شرائح خصم الجملة والكميات.
- سجل عملاء متكامل يوضح إجمالي المشتريات، رصيد المتبقي والمديونيات، وتاريخ الطلبات.

### 3. 🔄 مسار الإنتاج والطباعة (11 مرحلة معتمدة)
مسار دقيق يضمن تتبع كل مرحلة دون أخطاء:
1. `طلب جديد` (New)
2. `عرض سعر` (Quotation)
3. `موافقة العميل` (Approved)
4. `تجهيز الملف` (Slicing & G-code)
5. `انتظار الطباعة` (Print Queue)
6. `جاري الطباعة` (Printing) ⚡ *(تفعيل الخصم الآلي للخامات)*
7. `فحص الجودة` (QC Inspection)
8. `التشطيب والتجميع` (Post-processing)
9. `التغليف` (Packaging)
10. `الشحن والتسليم لشركة الشحن` (Shipping)
11. `تم التسليم والتحصيل` (Delivered)

> **قاعدة أمان المخزون:**
> حفظ عروض الأسعار لا يخصم أي جرام من المخزون مطلقاً. يتم الخصم التلقائي فقط عند دخول الطلب مرحلة «جاري الطباعة» مع قيد أمان يمنع تكرار الخصم لنفس الطلب (Idempotent).

### 4. 🧵 المخزون المتكامل (Full Inventory & Stock Ledger)
- **بكرات الفلمنت**: تتبع نوع الخامة (PLA+, PETG, TPU, ABS)، اللون، الماركة، والوزن المتبقي بدقة الجرام.
- **المستلزمات التجميعية (Hardware)**: مغناطيس نيوديميوم بمختلف مقاساته، مسامير M3، سوبر جلو، معجون ودهانات، وأرجل مطاطية.
- **مواد التغليف**: كراتين كرافت (M, S)، رول بابل راب، أكياس سيلد، وملصقات هوية البراند.
- **المنتجات تامة الصنع**: جرد القطع الجاهزة للتسليم الفوري.
- **سجل حركات المخزون (Stock Ledger)**: توثيق دقيق لكل عملية (توريد، صرف للإنتاج، هالك، أو تسوية جردية).

### 5. ⚙️ ملف تشغيل طابعة Elegoo Neptune 4 Pro
- معايرة دقيقة لتكلفة ساعة تشغيل الماكينة:
  - استهلاك الكهرباء (220W × 2.5 ج.م/كيلوواط) = **0.55 ج.م/ساعة**.
  - إهلاك الطابعة (سعر الشراء 22,000 ج.م ÷ 6,000 ساعة عمر افتراضي) = **3.67 ج.م/ساعة**.
  - المستهلكات والصيانة الدورية (نوزل، شحم، سطح طباعة) = **5.00 ج.م/ساعة**.
  - **إجمالي تكلفة تشغيل ساعة الماكينة = 9.22 ج.م/ساعة**.

### 6. 🔒 الأمان، النسخ الاحتياطي والعمل أوفلاين
- يعمل النظام بالكامل محلياً دون اشتراط وجود إنترنت (Offline-First).
- تصدير واستيراد نسخة احتياطية كاملة JSON بضغطة زر لحماية كافة البيانات.
- بنية تحتية برمجية مفصولة تسمح بالربط المستقبلي مع Firebase أو Supabase أو Google Sheets.

## 🧪 تشغيل الاختبارات الآلية

يحتوي النظام على حزمة اختبارات برمجية تغطي كافة الوظائف الحسابية وحركات المخزون:

```bash
npm test
```

جميع الاختبارات (10 من 10) تجتاز الفحص بنجاح.

## 💻 التشغيل السريع

افتح ملف `index.html` في أي متصفح، أو عبر إضافة Live Server في محرر الأكواد.
للوصول للحاسبة الكلاسيكية السابقة، تجد رابطاً مخصصاً لها في أسفل القائمة الجانبية أو عبر المسار: `legacy/calculator/index.html`.
